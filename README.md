# Документация по проекту анализа данных в деревообрабатывающей отрасли

## Обзор проекта

Этот проект представляет собой систему для обработки и анализа данных по компаниям в отрасли "Промышленность" (товарная группа "Деревообработка") на основе данных из Excel-файла (`продукция_выручка2.xlsx`). Система собирает, очищает, обогащает данные и предоставляет аналитику: ранжирование компаний по прибыльности, анализ динамики цен и продаж, категоризацию продуктов, визуализации (графики, тепловые карты) и статистику.

Цель — отразить емкость предложения (объемы продаж), цены и динамику для ключевых продуктов по компаниям за период 2022–2024 гг. Компании ранжируются от крупных к мелким (на основе композитного рейтинга: прибыль, рентабельность, стабильность, разнообразие продуктов).

Проект реализован на Python с использованием библиотек: pandas, numpy, matplotlib, re, collections. Он состоит из двух модулей (`data_processing.py`, `analyzer.py`) и Jupyter Notebook (`final_analysis.ipynb`) для демонстрации.

### Ключевые возможности
- **Сбор и обработка данных**: Автоматическая загрузка из Excel, очистка (нормализация колонок, числовых значений), обогащение (расчет выручки, категоризация продуктов на основе ключевых слов).
- **Анализ и ранжирование**: Расчет метрик (прибыль, рентабельность, стабильность), композитный рейтинг компаний.
- **Визуализации**: Графики динамики цен/продаж, доли рынка, распределения цен, тепловые карты корреляций.
- **Категоризация продуктов**: Автоматическая на основе анализа ключевых слов (например, "плиты", "пиломатериалы", "целлюлоза_бумага").
- **Статистика**: Общая сводка (количество строк, компаний, продуктов, ценовые статистики) и по категориям/продуктам.

Проект соответствует задаче: фокус на крупных компаниях (ранжирование), сбор данных по товарам (продукция, цена, объем, выручка) за период с годовой частотой.

## Структура кода

### 1. Модуль `data_processing.py` (Класс `WoodIndustryDataProcessor`)
Этот модуль отвечает за предобработку данных.

#### Инициализация
- `__init__(self, file_path)`: Устанавливает путь к Excel-файлу.

#### Основные методы
- `_clean_column_name(self, column_name)`: Очищает названия колонок (нижний регистр, замена пробелов на "_", удаление лишних символов).
- `_analyze_product_keywords(self, product_series)`: Анализирует ключевые слова в названиях продуктов (использует Counter для подсчета, фильтрует стоп-слова). Возвращает словарь топ-слов.
- `_create_categories_from_data(self, product_series)`: Создает категории продуктов на основе ключевых слов (например, 'плиты' для слов вроде 'мдф', 'фанера'). Расширяет паттерны динамически.
- `_smart_categorize_product(self, product_name)`: Категоризирует продукт по сходству с паттернами (счетчик совпадений, fallback на 'прочее').
- `load_data(self)`: Загружает данные из Excel, очищает колонки и числовые значения.
- `clean_data(self)`: Очищает данные (числовые/текстовые колонки, обработка NaN).
- `enrich_data(self)`: Обогащает данные (категоризация, нормализация года, расчет выручки если отсутствует).
- `analyze_categorization_quality(self)`: Анализирует качество категоризации (статистика по категориям, примеры продуктов).
- `calculate_company_metrics(self)`: Рассчитывает метрики компаний (аггрегация по прибыли/выручке, рентабельность, стабильность, композитный рейтинг и финальный ранг).
- `get_data_summary(self)`: Возвращает сводку данных (количество строк, компаний, продуктов, годы, статистика цен).
- `run_full_preprocessing(self)`: Полный цикл: загрузка, очистка, обогащение, анализ качества, вывод сводки. Возвращает обработанный DataFrame.

#### Пример использования
```python
processor = WoodIndustryDataProcessor('продукция_выручка2.xlsx')
df = processor.run_full_preprocessing()
```

### 2. Модуль `analyzer.py` (Класс `WoodIndustryAnalyzer`)
Этот модуль отвечает за анализ и визуализации на основе обработанного DataFrame.

#### Инициализация
- `__init__(self, processed_df)`: Принимает обработанный DataFrame.

#### Основные методы
- `plot_company_ranking(self, company_metrics, top_n=10)`: Визуализирует топ-N компаний (графики: прибыль, рентабельность, количество продуктов). Использует subplots.
- `plot_price_dynamics(self, company_name=None, product_category=None)`: Анализ динамики цен и объемов продаж для топ-3 продуктов (фильтр по компании/категории). Графики: линии с маркерами.
- `plot_product_analysis(self, product_name)`: Анализ конкретного продукта (графики: цены по компаниям, доля рынка (pie), объемы продаж (bar), распределение цен (boxplot)). Выводит статистику (_print_simple_stats).
- `_print_simple_stats(self, product_data, product_name)`: Печатает статистику по продукту (средняя цена, объем, выручка, топ-компании).
- `create_correlation_heatmap(self, company_name)`: Тепловая карта корреляций числовых показателей для компании.
- `plot_category_analysis(self)`: Анализ по категориям (графики: выручка, цена, количество продуктов, объем продаж). Выводит статистику.

#### Пример использования
```python
analyzer = WoodIndustryAnalyzer(df)
company_metrics = processor.calculate_company_metrics()
analyzer.plot_company_ranking(company_metrics)
analyzer.plot_product_analysis('брус')
```

### 3. Jupyter Notebook `final_analysis.ipynb`
- Импортирует модули и классы.
- Запускает предобработку (`processor.run_full_preprocessing()`).
- Ранжирует компании и выводит топ-10 по прибыльности.
- Анализирует ключевые продукты (например, 'брус') с визуализациями и статистикой.

## Сильные стороны анализа
- **Автоматизация и масштабируемость**: Автоматическая категоризация продуктов на основе реальных данных (без ручного ввода), что позволяет легко адаптировать к новым датасетам. Ранжирование компаний фокусируется на крупных (по прибыли/рентабельности), как рекомендовано.
- **Комплексный подход**: Комбинирует количественный анализ (метрики, корреляции) с визуализациями (графики, карты), делая выводы интуитивными. Учитывает динамику во времени (цены/продажи по годам).
- **Глубина инсайдов**: Выявляет ключевые слова, доли рынка, стабильность прибыли. Например, высокая рентабельность у мелких компаний (Лестех 32.4%), но доминирование крупных по объему.
- **Робастность**: Обработка ошибок (NaN, некорректные значения), расчет недостающих полей (выручка). Поддержка фильтров (по компании/категории/продукту).
- **Соответствие задаче**: Отражает "сколько товара Y по какой цене в какой момент времени продавала компания X" через аггрегацию по годам.

## Выводы по анализу
- **Рынок доминируют крупные игроки**: Илим лидирует по прибыли (50 млрд руб), но с фокусом на целлюлозу/бумагу. Компании вроде ВЛПХ и Сокольского комбината сильны в объемах пиломатериалов (например, 'брус' — 1.9 млн шт общий объем).
- **Динамика**: Цены и продажи растут с 2022 по 2024 (из графиков), но рентабельность варьируется (высокая у специализированных, как МДФ 29.8%).
- **Категории**: 'Пиломатериалы' и 'плиты' — ключевые по выручке/объему.
