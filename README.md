## Обзор проекта

Проект команды №10 посвящён ранжированию деревообрабатывающих компаний и выводу статистики их продаж на основе данных из файла `продукция_выручка2.xlsx`. Мы собрали информацию по 10 ключевым компаниям, включая выручку, объёмы продаж, цены и динамику за 2022–2024 гг.


**Цели проекта:**
- Оценить ёмкость рынка (объёмы продаж) и динамику цен по продуктам.
- Проранжировать компании по финансовым показателям (прибыль, рентабельность).
- Выявить лидеров и тенденции в отрасли.

Анализ выполнен в двух взаимодополняющих частях:
1. **Анализ в Microsoft Excel** — работа с данными, сводные таблицы, расчёты и визуализации.
2. **Автоматизация на Python** — обработка, аналитика, категоризация и интерактивный веб-дашборд для демонстрации результатов.

## Анализ в Microsoft Excel

Часть работы команды выполнена в Excel с использованием сводных таблиц, формул и визуализаций для детального изучения данных.

**Выполненные задачи:**
- Рассчитаны общие показатели: выручка, прибыль и объёмы продаж по компаниям и годам.
- Детализирована продукция: для каждого товара вычислены суммарный объём, выручка, средняя цена в разрезе компаний.
- Ключевые метрики компаний: суммарная выручка/прибыль, рентабельность, доля в общей выручке.
- Построены визуализации: диаграмма долей выручки, графики динамики цен по позициям за 2022–2024 гг.
- Сформированы сводные таблицы с фильтрами для удобного анализа.

**Результат**: Получена полная картина рынка с детализацией по продукции и динамикой показателей. Это основа проекта, позволившая выявить ключевые тенденции и подготовить данные для автоматизации.

## Автоматизированный анализ на Python

Для ускорения обработки и создания интерактивных инструментов реализована Python-часть проекта.

**Структура:**
- `data_processing.py`(pandas, numpy, re, collections): класс для загрузки, очистки, обогащения и категоризации данных.
- `analyzer.py`(matplotlib, pandas, numpy): класс для визуализаций и расчётов метрик.
- `final_analysis.ipynb`: Jupyter Notebook с примерами анализа.
**Возможности:**
- Автоматическая категоризация продуктов по ключевым словам.
- Расчёт композитного рейтинга компаний.
- Визуализации: графики цен, доли рынка, объёмов продаж.

### Интерактивный веб-дашборд (Streamlit)
На базе Python создан веб-дашборд (`app.py`), дополняющий Excel-анализ.

**Возможности дашборда:**
- Топ-10 компаний с таблицей и графиками.
- Поиск по ключевому слову (например, "брус") — анализ группы продуктов.
- Детальный анализ конкретного продукта из группы.
- Динамика цен с фильтрами по компании/категории.
- Скачивание статистики в Excel.

**Запуск:**
```bash
python3 -m streamlit run app.py
```
Дашборд открывается в браузере и служит для демонстрации результатов.
